# Willow Cafe Website

A responsive cafe website developed as a university group project. It provides visitors with information about the cafe, menu, and reservation options.

## Live Website

[Visit Willow Cafe Website](https://winnieee1.github.io/Willow-Cafe-Website/)

## Features

- **Home Page** – Introduces the cafe and its concept.
- **Menu Page** – Showcases food and beverage selections.
- **About Page** – Provides information about the cafe.
- **Contact Page** – Displays contact details.
- **Reservation Form** – Provides a form for reservation requests.
- **Sign In & Sign Up** – Provides user login and registration interfaces.
- **Responsive Layout** – Adapts to different screen sizes.

## Technologies Used

- HTML
- CSS
- JavaScript
